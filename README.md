# Asbest Professionals – premium conceptdemo (LJ Studio)

Alle HTML, CSS en JS staan in de hoofdmap. Geen build nodig. GitHub Pages werkt onder `/asbest-professionals/` dankzij relatieve paden `./`.

## Belangrijk vóór livegang
- De demo is **noindex** en `robots.txt` blokkeert crawlers. Verwijder pas na akkoord en correcte domeinkoppeling.
- Canonical en sitemap wijzen alvast naar `https://www.asbest-professionals.nl/`; dit is alleen een **beoogde officiële URL**. DNS/redirect www→niet-www (of omgekeerd) moet nog worden ingericht en door domeineigenaar worden goedgekeurd.
- Originele projectfoto's zijn nog niet één-op-één gekoppeld. Er worden twee externe afbeeldingen van de huidige website gebruikt, herhaald als illustratie. Geen foto-bestanden in de ZIP.
- Origineel logo is niet lokaal beschikbaar. Tijdelijk typografisch AP-logo. Vervang later door door eigenaar aangeleverd bestand.
- dNAA procescertificaat en FiberCover worden vermeld zoals op huidige site, zonder niet-geverifieerde certificaatnummers of actuele geldigheidsclaim.
- Formulier opent mailto. Voor echte inzendingen is backend/formulierdienst met privacy- en beveiligingsinstellingen nodig.
- Dit is een concept, niet de officiële website.
- De inhoud over regelgeving moet voor publicatie worden gecontroleerd op actuele Nederlandse regels en projectspecifieke vereisten.

## Upload
Upload alle bestanden uit deze ZIP naar de root van GitHub, vervang bestaande bestanden. `assets/` hoeft niet aangemaakt te worden voor deze versie.
